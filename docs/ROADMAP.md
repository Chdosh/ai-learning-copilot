# AI Learning Copilot 路线图

## 定位

轻量级跨平台桌面学习助手：在任何英文软件界面、报错、文档截图中，快速获得 OCR 原文、中文翻译、小白解释、关键术语，并自动沉淀为个人知识库。

当前阶段不做账号体系、云同步、团队权限，优先保证启动快、调用快、操作少。

## 当前工作流

1. 用户按全局快捷键（默认 `Ctrl + Alt + T`）或点击「按下截图」。
2. 应用隐藏主窗口并打开全屏截图遮罩。
3. 用户拖拽选择任意区域。
4. 应用保存临时截图。
5. RapidOCR 本地识别中英文文字。
6. 云端 AI 流式返回结构化结果。
7. 结果弹窗实时显示翻译和解释，完成后展示术语与学习建议。
8. SQLite 保存完整记录（截图、原文、翻译、解释、会话、术语）。

## 版本计划

### beta0.5（当前）
- 工作台学习方向管理：领域 / 场景 / 背景摘要 / 回答偏好，新建、编辑、快速切换
- 全局截图入口，悬浮结果窗（流式渲染、追问、重试、字号调节）
- 学习概览：历史记录索引、阅读面、追问
- 术语本：自动提取、收藏、复习次数、Anki 导出
- 单实例运行、托盘常驻、便携数据目录

### beta 后期
- 术语本复习流程完善（间隔重复）
- 自动分类：报错 / AI 概念 / Python / 数据库 / 网络 / 文档
- 数据管理：历史清理、数据库备份 / 恢复 / 导出

### 1.0
- embedding 语义搜索，把历史记录升级为可检索的个人知识库
- Windows 安装包（PyInstaller），再适配 macOS / Linux 权限差异
- 保持 OCRProvider 边界，后续可接 Windows 系统 OCR
- 截图保存优先使用 `mss` 原生物理像素，避免高 DPI 缩放导致 OCR 输入模糊
- 体验与安装稳定性稳定后，评估 Tauri + React 重写方案

## 架构原则

- 本地优先：OCR 与数据存储全部本地化，AI 调用可替换
- 会话为核心：每次截图 / 粘贴 = 「原文 → 翻译 / 解释 → 追问」的学习线程
- 学习方向为上下文：领域 / 场景影响 AI 的解释口径

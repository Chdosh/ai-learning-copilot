# AI Learning Copilot

> 把屏幕上的内容，变成可以理解、可以追问、可以回看的知识。

AI Learning Copilot 是一款面向技术学习的 Windows 桌面助手。

当你遇到英文界面、技术文档、代码片段或报错信息时，不必在截图工具、翻译器、聊天窗口和笔记之间来回切换：框选内容，先看懂；继续追问，再弄清；有价值的术语和学习建议，最后留下来。

当前主线版本：**v0.8.0**
下载地址：[GitHub Releases](https://github.com/Chdosh/ai-learning-copilot/releases)

## 它真正解决什么问题

普通的截图翻译通常只解决“这一段文字是什么意思”。

本项目更关注后面三步：

| 学习主线 | 你可以做什么 | 最终留下什么 |
| --- | --- | --- |
| **看懂** | 截图、翻译、解释、提取术语 | 一次可理解的结果 |
| **追问** | 围绕同一条记录继续提问 | 一条完整的学习上下文 |
| **沉淀** | 收藏术语、回看出处、处理学习建议 | 可检索的个人知识 |
| **回看** | 复习术语、查看相关知识、观察学习统计 | 持续学习的反馈 |

它不会把 AI 生成的内容直接改写进你的学习方向。学习方向由你自己维护；AI 产出主要沉淀为术语、学习建议和可回看的学习记录。

## 核心体验

### 1. 截图之后，先把问题讲明白

- 框选报错、文档、英文界面或代码片段；
- 获得翻译、解释、关键术语和学习建议；
- 围绕同一条截图继续追问，不必重复粘贴上下文；
- 结果以悬浮窗口呈现，适合边看资料边学习。

### 2. 学过的内容，不再只停留在聊天记录里

- 术语可以收藏，并回到原始截图查看出处；
- 收藏术语进入简化的间隔复习流程；
- 学习建议进入清单，可以完成或忽略；
- 学习页展示最近积累、相关知识和带理由的延伸推荐；
- 支持 Markdown、Anki 等导出方式。

### 3. 让学习方向和学习反馈形成闭环

- 按领域、场景、背景要点和回答偏好配置学习方向；
- 应用根据截图内容识别可能相关的方向，并在冲突时提示；
- 统计页提供近 90 天活动热力图、分类分布和连续学习天数；
- 学习方向的背景要点始终由用户手动编辑，不会被自动覆盖。

> 基础能力：OCR 在本地完成，数据保存在本地；Portable 版本提供稳定版检查和独立更新器。详细边界见[数据、隐私与安全](#数据隐私与安全)。

## 5 分钟上手

### 安装

1. 从 [GitHub Releases](https://github.com/Chdosh/ai-learning-copilot/releases) 下载 Windows x64 Portable ZIP。
2. 将 ZIP 完整解压到有读写权限的目录。
3. 运行 AI-Learning-Copilot.exe。
4. 首次运行后，在“设置 → AI 配置”填写 API Key、Base URL 和模型名称。
5. 点击测试连接，然后使用默认快捷键 Ctrl+Alt+T 框选一块内容。

### 推荐的第一次尝试

找一段你正在学习的报错或英文技术文档：

1. 框选它；
2. 先阅读翻译和解释；
3. 继续追问“这一步为什么这样做”；
4. 收藏一个真正想记住的术语；
5. 之后在学习页或术语本中回看。

### 使用前注意

- 必须完整解压，不能直接在压缩包内运行。
- 不要只复制主程序；移动时要保留整个程序目录。
- 不建议放在 C:\Program Files 等可能没有写入权限的位置。
- 当前版本未进行代码签名，SmartScreen 可能显示“未知发布者”。请确认来源并核对 SHA-256 后再运行。

## 数据、隐私与安全

### 什么留在本地

- 截图默认在本地处理，默认不保存截图文件；
- 历史记录、会话、术语、学习方向和复习事实保存在程序目录的 data/；
- API Key 保存在 Windows 凭据管理器中，不写入 app.db；
- 数据库备份不包含 API Key。

### 什么会发送到 AI 服务

OCR 图像默认不上传，但 OCR 得到的文本、追问内容和必要的提示上下文会发送到你配置的 AI 服务商。

因此：

- 不要把密码、令牌、个人隐私或未脱敏的敏感信息直接截图发送；
- 使用企业或第三方 API 前，先确认其数据处理政策；
- AI 输出可能存在错误，涉及生产、安全、法律、医疗或财务决策时请自行核验。

### 本地数据位置

~~~text
程序目录/
├─ AI-Learning-Copilot.exe
├─ AI-Learning-Copilot-Updater.exe
└─ data/
   ├─ app.db
   ├─ screenshots/
   ├─ exports/
   ├─ backups/
   └─ update.log
~~~

发布 ZIP 不包含 data/，这是为了避免把开发机或其他用户的数据带进安装包。

## 升级与迁移

### 内置更新

程序会检查 GitHub Releases 中的最新稳定版，下载匹配的 ZIP 和 SHA256SUMS.txt，完成校验后由独立更新器替换程序文件。

更新器不会覆盖 data/。但更新前仍建议备份重要数据。

### 手动升级

1. 退出程序和系统托盘进程；
2. 备份旧目录中的 data/；
3. 解压新版本；
4. 用新版本程序文件替换旧版本程序文件；
5. 保留原来的 data/；
6. 启动后检查历史记录和术语是否正常。

### 移动到同一台电脑的其他位置

移动整个程序目录，不要只移动 EXE。只移动 EXE 会让新位置创建一个空的 data/，看起来像历史记录丢失。

### 迁移到另一台电脑

复制整个程序目录，包括 data/。由于 API Key 存在 Windows 凭据管理器中，换电脑或换 Windows 账户后通常需要重新填写 API Key。

没有内置更新器的旧版本，例如 0.6.0 及更早版本，需要先手动安装一次支持更新的版本。

详细约定见：[Portable 更新发布说明](docs/UPDATE_RELEASE.md)。

## 当前版本边界

当前项目有意保持轻量：

- 仅支持 Windows 10 / 11 x64；
- 采用 Portable 免安装方式；
- 暂无安装器和代码签名；
- 暂无账号、云同步、多设备同步或团队空间；
- OCR 以中文和英文为主；
- embedding 语义搜索和更深层的历史知识关联尚未接入；
- 发布构建和 Release 上传目前仍以人工流程为主；
- 暂不提供 macOS / Linux 版本。

路线图见：[docs/ROADMAP.md](docs/ROADMAP.md)。

## 从源码运行

### 环境要求

- Windows 10 / 11 x64；
- Python 3.10 或更高版本；
- 一个可用的 OpenAI 兼容 API，或本地 Ollama。

### 安装与启动

~~~powershell
git clone https://github.com/Chdosh/ai-learning-copilot.git
cd ai-learning-copilot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
python -m app
~~~

开发模式不会执行 Portable EXE 的自动替换更新。

### 测试

~~~powershell
python -m pytest -q
python -m compileall -q app tests
~~~

测试覆盖数据层、知识积累、学习方向、学习页、统计组件、流式请求、更新检查和独立更新器的关键逻辑。真实桌面启动、旧版本升级和 Windows 凭据迁移需要在 Windows 环境中单独验收。

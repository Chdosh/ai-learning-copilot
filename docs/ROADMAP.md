# AI Learning Copilot 路线图

## 定位

轻量级跨平台桌面学习助手：在任何英文软件界面、报错、文档截图中，快速获得 OCR 原文、中文翻译、小白解释、关键术语，并自动沉淀为个人知识库。

当前阶段不做账号体系、云同步、团队权限，优先保证启动快、调用快、操作少。

## 当前工作流

1. 用户按全局快捷键（默认 `Ctrl + Alt + T`）或点击「按下截图」。
2. 应用隐藏主窗口并打开全屏截图遮罩。
3. 用户拖拽选择任意区域。
4. 应用保存临时截图。
5. RapidOCR 本地识别中英文文字。
6. 云端 AI 流式返回结构化结果。
7. 结果弹窗实时显示翻译和解释，完成后展示术语与学习建议。
8. SQLite 保存完整记录（截图、原文、翻译、解释、会话、术语）。

## 版本计划

### beta0.5（当前）

- 工作台学习方向管理：领域 / 场景 / 背景摘要 / 回答偏好，新建、编辑、快速切换
- 全局截图入口，悬浮结果窗（流式渲染、追问、重试、字号调节）
- 学习概览：历史记录索引、阅读面、追问
- 术语本：自动提取、收藏、复习次数、Anki 导出
- 自动分类：报错 / AI 概念 / Python / 数据库 / 网络 / 文档
- 数据管理：历史清理、数据库备份 / 恢复、Markdown / Anki 导出、数据库优化
- 单实例运行、托盘常驻、Windows Portable 单文件打包、便携数据目录

## 当前未实现与已知限制

- 仅发布 Windows 10 / 11 x64 Portable 版本；没有安装器、自动更新、代码签名和 macOS / Linux 构建。
- 术语本记录收藏与复习次数，但尚未实现基于遗忘曲线的间隔重复复习计划。
- embedding 服务与数据库表属于预留能力，尚未接入生成流程、语义搜索和知识关联界面。
- 不提供账号、云同步、跨设备同步、团队空间或在线数据托管。
- OCR 当前以 RapidOCR 中英文模型为主，尚未提供可视化语言包管理和 Windows 系统 OCR 切换。
- Portable 数据与 EXE 放在同一目录；只移动 EXE 不会自动带走旧 `data/`，换电脑后 API Key 也需要重新配置。

### beta 后续

- 完善术语复习流程，引入可解释的间隔重复计划。
- 增加首次启动引导、配置诊断和更清晰的错误恢复提示。
- 增加发布包自动构建、校验文件、升级迁移检查和可选自动更新。
- 在不牺牲本地优先原则的前提下接入 embedding 语义搜索和历史知识关联。

### 1.0

- 可选 Windows 安装器、代码签名，再适配 macOS / Linux 权限差异
- 保持 OCRProvider 边界，后续可接 Windows 系统 OCR
- 截图保存优先使用 `mss` 原生物理像素，避免高 DPI 缩放导致 OCR 输入模糊
- 体验与安装稳定性稳定后，评估 Tauri + React 重写方案

## 架构原则

- 本地优先：OCR 与数据存储全部本地化，AI 调用可替换
- 会话为核心：每次截图 / 粘贴 = 「原文 → 翻译 / 解释 → 追问」的学习线程
- 学习方向为上下文：领域 / 场景影响 AI 的解释口径

# AI Learning Copilot 路线图

## 定位

轻量级桌面学习助手：在英文软件界面、报错、文档截图中，快速获得 OCR 原文、中文翻译、小白向解释和关键术语，并沉淀为本地个人知识库。

不做账号体系、云同步、团队权限；优先保证启动快、调用快、操作少。

## 当前工作流

1. 用户按全局快捷键（默认 `Ctrl+Alt+T`）或点击「按下截图」。
2. 应用隐藏主窗口并打开全屏截图遮罩。
3. 用户拖拽选择区域。
4. 应用保存临时截图。
5. RapidOCR 本地识别中英文文字。
6. AI 流式返回结构化结果。
7. 悬浮结果窗实时显示翻译和解释，完成后展示术语与学习建议。
8. SQLite 保存完整记录（截图、原文、翻译、解释、会话、术语）。

## 已知限制

- 仅发布 Windows 10 / 11 x64 Portable 版本；没有安装器、自动更新、代码签名，也没有 macOS / Linux 构建。
- 术语本有收藏与复习计数，但还没有基于遗忘曲线的间隔复习计划。
- embedding 表结构已预留，但语义搜索和知识关联界面尚未接入。
- OCR 使用 RapidOCR 中英文模型，暂无可视化语言包管理和系统 OCR 切换。
- Portable 数据与 EXE 同目录；只移动 EXE 不会带走旧 `data/`，换电脑后 API Key 需要重新配置。

## 架构原则

- 本地优先：OCR 与数据存储全部本地化，AI 调用可替换
- 会话为核心：每次截图 = 「原文 → 翻译 / 解释 → 追问」的学习线程
- 学习方向为上下文：领域 / 场景影响 AI 的解释口径
